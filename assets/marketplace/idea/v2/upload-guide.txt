可配合使用的英文描述草稿

Git AI is an AI commit message generator for IntelliJ IDEA and compatible JetBrains IDEs.
Commit a quick draft, then keep coding while your configured model polishes the message
in the background. Use Conventional Commits, Gitmoji, plain text, or subject and body.

The native Git AI tool window lets you inspect AI history, retry generation, restore
your original draft, cancel active polishing, or skip AI. Connect an OpenAI-compatible
API, Anthropic, Google, or a local Ollama model, and choose your output language and style.

Polishing uses the recorded commit tree and parents. The recorded ref is updated only
if it has not moved; model failures leave the original commit unchanged.
