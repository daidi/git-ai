建议配合使用的英文描述（可复制，尚未发布）

AI commit messages, polished after commit.

Git AI is an AI commit message generator for IntelliJ IDEA and compatible JetBrains IDEs.
Commit a quick draft, then keep coding while your configured model polishes the message
in the background. Choose Conventional Commits, Gitmoji, plain text, or subject and body.

Use the native Git AI Tool Window to follow progress, inspect AI history, retry generation,
restore your original draft, or cancel active polishing. With the queue push policy,
eligible pushes wait until polishing finishes.

Connect an OpenAI-compatible API, Anthropic, Google, or a local Ollama model. Configure
your provider, output language, and message format in Settings / Preferences → Tools → Git AI.
Cloud providers require your own API key; Ollama supports local inference.

Polishing uses the exact recorded commit tree and parents. It updates the recorded ref
only if it has not moved. A model failure leaves your original commit unchanged.

主要关键词已自然包含在描述中：AI commit message generator、IntelliJ IDEA、
Conventional Commits、Gitmoji、Ollama、JetBrains IDEs。
